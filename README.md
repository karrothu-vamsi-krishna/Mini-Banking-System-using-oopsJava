# BankJava 🏦

A simple **Banking System** built using Java that demonstrates Object-Oriented Programming concepts like Inheritance, Encapsulation, and Polymorphism.

## Features
- Create Savings Account and Current Account
- Deposit and Withdraw money
- Check Account Balance
- Add Interest to Savings Account
- Transfer Funds between accounts

## Project Structure
```
BankJava/
└── Bank/
    ├── Account.java        # Base class for all accounts
    ├── Bank.java           # Manages all bank accounts
    ├── CurrentAccount.java # Current account with overdraft limit
    ├── SavingsAccount.java # Savings account with interest
    └── Main.java           # Entry point of the program
```

## How to Run

**Step 1 - Navigate to project folder:**
```bash
cd BankJava
```

**Step 3 - Compile:**
```bash
javac Bank/*.java
```

**Step 4 - Run:**
```bash
java Bank.Main
```
